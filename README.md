# Family Tracker

Семейный трекер на **Expo SDK 57 / React Native 0.86**: участники группы видят друг
друга на карте, приглашают по коду, а устройство с ролью «Ребёнок» передаёт
геолокацию в фоне (Android).

## Требования

- Node.js 20+
- Android Studio (SDK 36) / Xcode
- **Development build обязателен**: используются MapLibre и собственный нативный
  модуль `location-tracking`. В Expo Go приложение не запустится.

## Запуск

```bash
npm install
npm run android        # expo run:android, пересобирает dev client при нативных изменениях
npm run typecheck      # tsc --noEmit
```

Для iOS: `npx expo run:ios` (фоновое отслеживание пока реализовано только на Android).

### Конфигурация

Адрес API и стиля карты можно переопределить через `.env.local` (Metro встраивает
`EXPO_PUBLIC_*` при сборке):

```bash
EXPO_PUBLIC_API_URL=https://your-host/api
EXPO_PUBLIC_MAP_STYLE_URL=https://your-host/tiles/styles/colorful/style.json
```

По умолчанию используются текущие адреса из `src/constants/config.ts`.

> Нативный Android-сервис хранит собственную копию URL загрузки координат:
> `modules/location-tracking/android/src/main/java/expo/modules/locationtracking/LocationTrackingService.kt`.
> При переезде backend меняйте оба места.

## Структура

## Дизайн-система

Все визуальные значения живут в `src/design/tokens.ts`: палитры light/dark,
шкала отступов (4–40), радиусы, типографика, тени и цвета аватаров.
`src/design/paper.ts` проецирует токены в тему React Native Paper, поэтому все
Paper-компоненты автоматически следуют палитре.

Правила для новых экранов:

1. Экран — `<Screen>` + `<AppBar>`, контент — `<Card>`/`<Section>`.
2. Текст — только `<AppText variant tone>`, без ручных fontSize/color.
3. Одно главное действие на экран — `<AppButton>` (contained), остальное — text/outlined.
4. Вторичные сценарии (создание, вход по коду, добавление участника) — `<BottomSheet>`.
5. Загрузка — `<Skeleton>`, пусто — `<EmptyState>`, ошибка — `<ErrorState>`, некритичное — `<InlineBanner>`.
6. Обратная связь — `<Toast>` (`useToast`), а не `Alert` (Alert оставлен только для подтверждения удаления/выхода и объяснения разрешений).
7. Цвета берутся из `useAppTheme()`, никаких hex в экранах.
8. Тап-зоны не меньше 44×44 (`IconAction` уже такой).

Тема переключается в «Аккаунт → Приложение → Тема» и сохраняется в AsyncStorage.

## Что было исправлено

### Функциональные баги

1. **Вход по коду был недоступен**: экран `JoinGroup` существовал, но вкладку
   заменили на «Аккаунт», и маршрута не осталось. Маршрут восстановлен в стеке
   групп, точка входа — «+» на экране групп.
2. **Трекинг не перезапускался после выхода и повторного входа**: флаг
   `isTrackingStarted` не сбрасывался. Теперь `stopBackgroundTracking` всегда его сбрасывает.
3. **Падение на iOS**: нативный модуль там пустой, а JS вызывал `setCredentials`
   напрямую. Добавлена проверка доступности методов и платформы.
4. **Фоновое разрешение никогда не запрашивалось** (только fine/coarse), из-за
   чего Android останавливал геолокацию при закрытии приложения. Теперь
   запрашивается `ACCESS_BACKGROUND_LOCATION` с объяснением, плюс
   `POST_NOTIFICATIONS` для Android 13+.
5. **Истёкший токен не разлогинивал**: 401 удалял токен из хранилища, но UI
   оставался авторизованным. Теперь 401 очищает сессию, останавливает трекинг и
   возвращает на экран входа.
6. **Дублирование логики входа/регистрации/восстановления сессии** — сведено в
   `AuthContext`; профиль кешируется, чтобы приложение открывалось офлайн.
7. **`console.log` на уровне модуля** в `RegisterScreen` и отладочные логи удалены.
8. **Захардкоженные URL** API и стиля карты вынесены в конфиг + env.
9. **Мёртвый код**: удалены `MapScreen.maplibre.tsx` (дубликат), старый
   `theme.ts`, `RefreshButton`, `utils/common.ts`; из зависимостей убраны
   `react-native-maps`, `react-native-webview`, `react-native-vector-icons`,
   добавлен `react-native-safe-area-context`.
10. **Опрос карты каждые 15 секунд даже в фоне** заменён на 20 секунд только при
    активном экране и активном приложении, с немедленным обновлением при возврате.
11. **Safe area**: Android 15 работает edge-to-edge, а экраны этого не учитывали.
    Добавлены `SafeAreaProvider` и `Screen`.
12. **`tsconfig.json`**: убран дублирующий ключ `jsx`, включён автоматический runtime.
13. **Нет таймаута и нормализации ошибок** — axios-клиент теперь даёт единый
    `ApiError` с человеческим текстом.
14. **Нет защиты от падений** — добавлен `AppErrorBoundary`.
15. **Не было состояний загрузки/пустоты/ошибки** — добавлены скелетоны,
    пустые состояния с CTA и повтор запроса.
16. **Смешение Paper и React Native компонентов** — единый UI-кит.
17. **Доступность**: 44×44 тап-зоны, `accessibilityLabel` у иконочных кнопок,
    контраст текста приведён к AA, текстовые статусы вместо только цвета.

### UX/UI

- Карта стала главным экраном без нагромождения: плавающая шапка, карусель
  участников, карточка выбранного человека, отдельные кнопки «показать всех» и
  «моё местоположение».
- Один акцентный цвет, спокойный фон, карточки с тонкой рамкой, крупная
  типографика, единые отступы.
- Полноценная тёмная тема.
- Приглашение: код создаётся автоматически, показывается крупно по символам,
  есть копирование, «Поделиться», обратный отсчёт и перегенерация.
- Аккаунт: профиль, статус трекинга, разрешения, настройки батареи, обновления,
  тема, выход.
- Ошибки валидации показываются под полем, а не в алертах.

## Известные ограничения и следующие шаги

1. **Нативный сервис геолокации**:
   - `PRIORITY_HIGH_ACCURACY` каждые 30 с заметно расходует батарею — стоит
     перейти на `BALANCED_POWER_ACCURACY` + `setMinUpdateDistanceMeters`;
   - новый `OkHttpClient` создаётся на каждую отправку — сделать общим;
   - нет очереди при офлайне и ретраев;
   - URL захардкожен;
   - хранится только один `groupId` (одна детская группа) — при необходимости
     поддерживать несколько групп нужен нативный рефакторинг.
2. **Нет refresh-токена**: по истечении JWT пользователь разлогинивается.
3. **iOS**: фоновый трекинг не реализован (модуль пустой).
4. **Удаление участника**: в UI нет, так как неизвестен контракт backend.
5. **Deep links**: схема `exp+familytrackerapp` есть только для dev client;
   для приглашений стоит добавить `scheme` + `linking` и открывать `JoinGroup` по ссылке.
6. **Системная тема**: `userInterfaceStyle` в `app.json` — `light`; тема
   переключается внутри приложения. Для следования системе нужен `expo-system-ui`
   и `userInterfaceStyle: "automatic"`.
7. **TLS на IP-адрес**: лучше переехать на домен с валидным сертификатом.
8. **Тесты**: нет ни unit-, ни e2e-тестов; минимум — тесты на `format.ts`,
   `validation.ts` и редьюсеры `AuthContext`.
